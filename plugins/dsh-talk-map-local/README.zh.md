# dsh-talk-map · 对话地图

[English](README.md) | 中文

DeepSeek Harness（dsh）的可视化对话地图插件：把你的每一个会话变成白板上的一张卡片。

- **空间记忆代替脑内记忆**：卡片自由摆放 + 网格吸附，位置永远不会被自动打乱——你记得"那个对话在左下角"，它就一直在左下角。为 ADHD 用户设计，对所有人有效。
- **双击即聊**：双击白板空白处（或右键「新对话」）直接在点击处开一个新会话并进入，不弹任何编辑框；地图上立刻出现一个虚线临时框（未开始、没有右键菜单、不能拉线），发出第一条消息后转正为正式卡片并同步主页标题；没发消息就关掉，会自动删框并归档这个空会话。
- **连线分叉**：从一张卡的连接点拉线到空白处松开，落点出现一个虚线占位框，右侧会话窗口同时打开「分叉设置」：选注入方式（不继承 / 摘要注入 / 完整对话）、编辑摘要、工作区 / 模型 / 模式、附件、第一句话；点「开新对话」才真正创建会话并把占位框转正。关掉设置面板占位框会保留，点它可以重新打开；占位框右上角的 × 可以删掉它。
- **草稿框（可选）**：想先选工作区 / 模型 / 模式、粘图片或写第一句时，右键「新对话（先填写）…」或 Shift+双击空白打开草稿框；粘贴或拖入的图片与普通文件会随第一条消息上传（只发附件也可以）。
- **侧边窗口切模式**：右侧会话窗口里开新对话时，工作区旁边可以选模式（标准 / PTC / 极简 / 创造，以及部署里的自定义模式）；发出第一条消息后，模式显示在窗口标题右边——和主页的新对话页、会话标题栏一致。模式决定工具与提示词组合，所以 dsh 只允许在第一条消息前切换。
- **卡片正面 = 恢复现场**：标题、摘要的"下一步"、相对时间、运行状态。回来扫一眼就知道该干嘛。
- **自动摘要**：会话空闲后自动生成三字段摘要（概要 / 关键结论 / 下一步），用你部署里的默认模型；卡片上的 ⟳ 可手动重生成。
- **中英双语界面**：地图自己的文案可以选中文或英文。地图顶栏那颗药丸按钮循环切换 自动 → 中文 → English，「自动」跟随 dsh 本身的语言，选择会记住，重启也在。（摘要仍然跟随被摘要的那段对话的语言。）
- **血缘可见**：dsh 原生的 fork/子代理血缘自动画成虚线，你拉的注入线是实线。

## 安装

本仓库是本地插件 **`dsh-talk-map-local`** 的源码副本。构建产物（`lib/`、`client/`）已随仓库提交，免构建、无需 allowBuilds。

```sh
# 改了源码后重新构建
npm run build

# 然后把 client/ 与 lib/ 同步进本机已安装该插件的 profile：
#   ~/.dsh/profiles/<profile>/node_modules/dsh-talk-map-local/{client,lib}/
```

> 本仓库的提交与推送都不经过 GitHub 上的 `Tasihi89/dsh-talk-map`——那个仓库只是这个本地插件的原型来源；本地 git 也没有配置指向它的远程。

重启 `dsh web`，侧栏底部出现地图按钮。

## 使用

| 动作 | 效果 |
|---|---|
| 点侧栏地图按钮 / Esc | 开关地图 |
| 拖动卡片 | 摆放（16px 网格吸附，位置持久化） |
| 右键拖动 / 中键拖动空白 | 平移画布（右键拖动不会弹出菜单） |
| 双击空白 | 在该位置新建会话并打开，点击处出现虚线临时框；发出首条消息后转正 |
| 右键「新对话」 | 同上；临时框在未发送前没有右键菜单，关掉会自动删框并归档这个空会话 |
| Shift+双击空白 / 右键「新对话（先填写）…」 | 打开草稿框：选工作区/模型/模式、写第一句、加附件 |
| 双击卡片 | 打开该会话 |
| 点卡片 / 点空白 | 右侧会话窗口打开该会话 / 收起它（图钉锁定时不收） |
| 在草稿框粘贴/拖入图片或文件 | 发送时作为附件随第一条消息发出 |
| 从卡片的连接点拉线到空白 | 落点出现占位框并在右侧打开分叉设置；点「开新对话」创建并转正，关掉面板则占位框保留 |
| 卡片上的 ⟳ | 手动重新生成摘要 |
| 地图顶栏的语言按钮 | 循环切换 自动 → 中文 → English |
| 拖动会话窗口左边缘 | 调整右侧会话窗口宽度（双击恢复默认，方向键微调） |
| 右侧会话窗口里新对话的模式胶囊 | 切换这个会话的模式（第一条消息前有效；之后标题右边只读显示） |

## 数据存哪

- 画布数据（卡片位置、连线、摘要）：`$DSH_HOME/storages/talk_map.json`，走 dsh 官方 storage-domain，原子落盘。
- 会话本身：完全归 dsh 管，本插件只读会话、只在分叉时通过官方 API 创建新会话。
- 摘要生成用你配置的默认模型，走本地 dsh 的 LLM 通道；除此之外无任何外部请求。

## 兼容性

针对 deepseek-harness `0.2.2-rc.1` 开发（rc 阶段 API 可能漂移）。草稿卡附件额外依赖 `dsh-client-file-upload` 与 `dsh-client-ui-file-drag` 两个客户端条目，0.2.x 的 `dsh-web-app` bundle 自带。结构化契约集中在 `src/client/dsh.ts` 与 `src/host/dsh-host.ts`，升级排查从这两个文件开始。
